> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Telezon-S3 0.2 S3 protocol completeness: DeleteObject, ListObjectsV2, ListBuckets, corrected HEAD, Presigned GET/PUT, optional `message_id` on blobs.

**Architecture:** Split `app/s3` into handlers + XML/auth helpers; extend Storage ABC with `PutFileResult` and `delete_message`; keep FastAPI/Mongo/SigV4.

**Tech Stack:** Python 3.12, FastAPI, Motor, existing `app/s3/awssig`, pytest + httpx, fake in-memory storage for tests.

**Spec:** `docs/superpowers/specs/2026-07-29-s3-compat-0.2-design.md`

## Global Constraints

- DeleteObject: Mongo delete required path; TG delete best-effort; 204 even if object missing
- Presign: GET + PUT only; max 7 days
- List: ListObjectsV2 + ListBuckets only; no Create/DeleteBucket via S3
- `message_id` optional; legacy blobs skip TG delete
- S3 errors are XML, never JSON
- No multipart / delimiter / SSE / streaming refactor in this plan
- 4-space indent; match existing project style

```python
# app/storage/storage.py
from abc import ABC, abstractmethod
from pydantic import BaseModel

class PutFileResult(BaseModel):
    file_id: str
    message_id: int | None = None

class Storage(ABC):
    @abstractmethod
    async def put_file(self, file: bytes, filename: str) -> PutFileResult:
        ...

    @abstractmethod
    async def get_file(self, file_id: str):
        ...

    @abstractmethod
    async def delete_message(self, message_id: int) -> bool:
        ...
```

Account storage: `return PutFileResult(file_id=str(response.document.file_id), message_id=response.id)`  
Bot storage: use `result.message_id`.  
`delete_message`: call platform delete; on exception log and return False.

```python
class FakeStorage:
    def __init__(self):
        self.files = {}
        self.deleted_messages = []
        self._msg = 1
    async def put_file(self, file, filename):
        self._msg += 1
        fid = f"file-{self._msg}"
        self.files[fid] = file
        return PutFileResult(file_id=fid, message_id=self._msg)
    async def get_file(self, file_id):
        import io
        return io.BytesIO(self.files[file_id])
    async def delete_message(self, message_id):
        self.deleted_messages.append(message_id)
        return True
```
